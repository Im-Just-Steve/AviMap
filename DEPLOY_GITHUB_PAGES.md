# GitHub Pages deployment

This project is a static PWA and can be served from GitHub Pages.

If your repository is `im-just-steve/AviMap`:

1. Put the contents of this folder at the repository root.
2. In GitHub, open Settings → Pages.
3. Select the branch/folder containing the project.
4. Wait for the Pages deployment.
5. Open:

   https://im-just-steve.github.io/AviMap/

The PWA's relative paths are intentionally based at `./` so it works under the
`/AviMap/` repository path.

For the companion, build the Windows executable separately and distribute it
outside GitHub Pages.
