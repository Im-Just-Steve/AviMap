# AviMap aviation data

These files are generated by the GitHub Actions workflow from NATS AIS data.

- `uk-airspace.geojson` — derived from the current NATS UK ICAO AIP Dataset
  AIXM XML.
- `uk-reporting-points.geojson` — derived from the current NATS Visual
  Reference Points List.

The PWA reads these committed local GeoJSON files, so the browser does not
need direct access to the NATS dataset servers.

The workflow validates both generated datasets before replacing the repository
files. In particular, a zero-VRP or zero-airspace result will stop the workflow
and leave the existing committed data untouched.
